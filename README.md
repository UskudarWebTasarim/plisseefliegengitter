# Plissee Fliegengitter - Premium Insektenschutzlösungen

Professionelle Plissee Fliegengitter und Insektenschutzsysteme für Europa. Hochwertige Qualität, einfache Installation und zuverlässiger Schutz vor Insekten.

## Features

- **Bilingual Support**: German and Turkish language support with seamless switching
- **Responsive Design**: Optimized for all devices (desktop, tablet, mobile)
- **Modern UI**: Clean, professional design with Tailwind CSS
- **SEO Optimized**: Fast loading, semantic HTML, and optimized metadata
- **WhatsApp Integration**: Direct contact via WhatsApp for customer support

## Technologies Used

- **Next.js 15.1.6**: React framework for production
- **React 18.3.1**: UI library
- **Tailwind CSS v3.3.3**: Utility-first CSS framework
- **TypeScript**: Type-safe development
- **Lucide React**: Icon library

## Getting Started

First, install dependencies:

```bash
npm install
```

Then run the development server:

```bash
npm run dev
```

Open [http://localhost:3111](http://localhost:3111) with your browser to see the result.

## Build for Production

```bash
npm run build
npm start
```
